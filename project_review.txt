RentFlow - Project Review (Last Updated: 5 Months Ago)

🏠 Project Overview
RentFlow is a modern, full-stack Boarding House Management System designed to streamline property operations. It simplifies room allocation, billing, and maintenance tracking, and provides two main interfaces:
- Admin Portal: For property managers to oversee residents, handle automated billing, and track maintenance requests.
- Tenant Portal: A user-friendly dashboard for residents to pay rent, view room details, and submit repair requests.

💻 Technology Stack

Frontend (/frontend)
Built with a strong focus on premium design, fluid animations, and modern React paradigms.
- Framework: Next.js 15 (using the App Router) running on React 19.
- Styling: Tailwind CSS v4 combined with next-themes to support seamless Dark/Light mode transitions.
- Animations: Framer Motion for smooth kinetic typography and UI interactions.
- Icons: Lucide React.
- Data Fetching: Axios is set up for API communication.

Backend (/backend)
A robust, standalone RESTful API to handle business logic and database interactions.
- Runtime & Framework: Node.js with Express.js v5.
- Database: PostgreSQL (using the pg library). It connects to a local database named rentFlow_db and utilizes a specific schema (rentFlow_schema). The raw SQL schema is stored in rentFlow_db.sql.
- Authentication: Secured via JWT (jsonwebtoken) and Bcrypt (bcryptjs) for password hashing.
- File Uploads: Managed locally using Multer (saved in the /uploads directory).
- Automated Tasks: Uses node-cron to handle automated background tasks (specifically for generating bills via billingCron.js).

📂 Architecture & Key Files
- Frontend Structure: Adheres to the Next.js App Router structure with a src/ directory containing your UI components and routes.
- Backend Structure: Well-organized into logical directories:
  - routes/: API endpoint definitions (auth, admin, tenant, billing, requests).
  - controllers/: Core business logic for handling requests.
  - middleware/: Authentication and route protection logic.
  - cron/: Scheduled tasks for background jobs.
  - config/: Configuration files (e.g., db.js for Postgres connection).
- Root Level: There are some Supabase packages in the root package.json, which suggests there might have been some initial experimentation with Supabase, though the core backend currently strictly relies on a raw pg connection.

🚀 How to Run the Project Locally

1. Start the Backend:
Navigate to the backend folder and run the server (make sure your local PostgreSQL server is running and the database is configured).
> cd backend
> npm run dev
(Runs on http://localhost:5000)

2. Start the Frontend:
Open a new terminal, navigate to the frontend folder, and start the Next.js dev server.
> cd frontend
> npm run dev
(Runs on http://localhost:3000)

✨ Key Features

1. 🏢 Smart Room Allocation & Management
- Occupancy Tracking: Efficiently track available units, occupied rooms, and room details.
- Resident Assignment: An intuitive interface for admins to assign tenants to specific rooms.

2. 💳 Automated Billing & Payments
- Auto-Invoicing: The system uses scheduled background tasks to automatically generate monthly rent invoices.
- Payment Tracking: Admins can track the payment statuses of all tenants.
- Tenant Billing Portal: Residents can view their payment history and check upcoming balances.

3. 🛠️ Live Maintenance & Repair System
- Real-Time Requests: Tenants can submit repair requests directly from their dashboard.
- Issue Tracking: Admins receive these requests, and can assign, track, and mark them as resolved efficiently. 

4. 👥 Dual Portals
- Admin Portal: A comprehensive control panel for property managers to oversee everything (residents, billing, maintenance, and rooms).
- Tenant Portal: A dedicated, restricted dashboard for residents to manage their stay, check rent, and submit maintenance tickets.

5. ✨ Modern User Experience
- Dynamic Themes: Seamless transitions between sleek Dark Mode and professional Light Mode.
- Fluid Animations & Aesthetics: A high-end UI built with Tailwind CSS v4 and Framer Motion for smooth transitions and interactions.
- Responsive Design: Accessible across different devices.
